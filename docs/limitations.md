# Limitations

The current live source verifies discovery metadata only. It does not establish listing creation time, operator age, actual settlement, buyers, revenue, availability, rank or endpoint invocation. Resources are left-truncated at first observation. Merchant identity is unknown absent reliable identity data. No settlement or payer statistics can be inferred; missing activity is not zero activity. The initial sample is a single snapshot and cannot measure 14/30 day demand. LeftSock realized income is $0.
